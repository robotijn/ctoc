# Report tool

A small command-line tool that prints a report of build rows.

- Run the tests with `npm test` (Node's built-in test runner, `node:test`).
- The project has 2 test files under `tests/`. Keep this count true: a change that adds a
  test file updates it here.
- Plans live in `plans/`; every implementation slice runs the Iron Loop Steps 8 to 16.
