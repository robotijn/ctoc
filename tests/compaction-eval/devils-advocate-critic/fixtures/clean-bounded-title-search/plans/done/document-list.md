# The document list

## What the person gets

One list of every document the person owns or that is shared with them, newest first, on a
single page. There is no paging: the whole list is shown at once.

## Acceptance criteria

1. The list shows every document the person owns and every document shared with them, and no
   other document.
2. All of those documents appear on one page; there is no paging and no "load more".
3. The list is ordered newest first by last change.
